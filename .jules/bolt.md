## 2024-05-24 - Layout Thrashing in Unthrottled Scroll Listeners
**Learning:** Found two instances (`updateWork` and `onScroll` scroll spy) where scroll listeners fired on every scroll pixel without throttling. Animating layout properties like `width` rather than `transform` causes full reflows. Additionally, allocating new arrays (e.g. via `map`) inside a `requestAnimationFrame` loop creates unnecessary garbage collection overhead which degrades performance.
**Action:** Always throttle continuous events like `scroll` or `resize` using `requestAnimationFrame`. Group all DOM reads (measuring positions) together before DOM writes, but do so without creating intermediate arrays in hot loops. Use CSS properties that don't trigger reflow (`transform`, `opacity`) for animations and include `will-change: transform`.
