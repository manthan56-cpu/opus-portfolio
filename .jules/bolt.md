## 2026-10-10 - Layout Thrashing in Horizontal Scroll Event Listeners
**Learning:** In a vanilla JS project where horizontal scrolling is driven by JS `transform` updates inside a `scroll` event listener, reading `offsetLeft` or `offsetWidth` of elements immediately after writing to the DOM (`style.transform` / `style.width`) causes synchronous layout recalculation (layout thrashing) on every frame, resulting in significant performance bottlenecks.
**Action:** When creating high-frequency event handlers (like `scroll` or `mousemove`), ensure all DOM layout properties are read and cached outside the handler (e.g. in a resize listener or an initialization phase) so the event handler only performs writes and reads from the cache. Additionally, gate DOM `textContent` mutations behind checks for state changes.
